QCS Oracle Automation Architecture

QCS turns natural-language Oracle EBS R12 test instructions into generated pytest replay scripts for mixed OAF/web and Java Forms workflows. AI is allowed during recording and failure healing only. Normal replay is deterministic and resolves user-friendly script references through the object repository, Playwright, and the local Java Forms agent.

Record Once

AI watches screenshots, decides the next action, and the recorder stores structured actions.

Replay Often

Generated pytest scripts call a readable DSL and run without LLM calls in the normal path.

Repo Resolves

Friendly names map to Java-agent and Playwright descriptors in the repository.

Patch Review

Recorded and healed locator changes are reviewable. Do not silently merge AI changes.

Current Module Map

Keep changes inside the layer that owns the behavior. Generated files are useful to inspect, but lasting fixes belong in the generator, repo, recorder, or replay runtime.

CLI

qcs/__main__.py owns commands. qcs record records and generates immediately. qcs gen run is for manual regeneration; qcs gen validate <dir> runs the business-readability gate. qcs aliases validate and qcs aliases report manage the alias catalog. qcs repo validate checks the repository schema.

Recorder

oracle_ai_agent owns AI-guided recording. It performs deterministic login/open-form setup, sends only screenshots to AI, and maps actions locally to Java DOM.

Java Forms Agent

java-agent/ and qcs_java_agent extract, inspect, and replay Java Forms through the Java Attach API. Normal Forms execution must not use screenshot clicking.

Object Repository

qcs_repo stores forms and elements in repo/repo.db with YAML fallback and flow files under repo/. Current recording stores only actioned elements.

Generator

generator converts manifest steps into launchable pytest suites using the FormReplay DSL. generator/naming.py applies the alias catalog (config/aliases/) then a deterministic sanitiser to produce business-readable form_ref and element_ref names. generator/alias_catalog.py loads and validates per-domain alias JSON files. generator/script_validator.py provides the post-generation readability gate.

Replay Runtime

qcs_replay owns deterministic actions, assertions, Playwright helpers, Java ref resolution, and failure-only healing. qcs_replay.dsl adds the surface-aware DSL layer: RepositoryResolver, FormReplay, BrowserReplayBackend, JavaFormsReplayBackend, ReplayLogger, and typed exceptions. OracleReplay.form('form_ref') returns a FormReplay bound to the named form; controls are invoked from that object. qcs_replay.failure_bundle writes structured diagnostics (JSON + screenshots + Java snapshots) on step failure.

Control Plane Prototype

qcs_center is an early FastAPI job/agent backend. Evolve it into the management and artifact service.

Windows Worker Prototype

qcs_agent long-polls the center and runs jobs on a Windows desktop session. Oracle Forms automation is desktop-session bound.

Legacy Note

Do not reintroduce the old standalone Oracle MCP server path. Current Forms extraction and replay goes through qcs_java_agent and java-agent/.

Generated Script Contract

Users launch generated pytest scripts directly. The script should read like a business replay while still carrying deterministic ref and form_id values so runtime resolution stays stable.

What The Runtime Does

  • OracleReplay.login performs deterministic Playwright login with environment credentials.
  • OracleReplay.open_form navigates to RF.jsp, downloads JNLP, starts Forms, attaches the Java agent, and waits for readiness.
  • oracle_replay.form('form_ref') returns a FormReplay bound to the named form. Controls are invoked from that object: set_text, click, press_key, assert_text, etc.
  • form_ref and element_ref are business-readable names resolved through the alias catalog; qcs_repo maps them to Java-agent descriptors at runtime.
  • Technical Java IDs (java_*, _alt_*, toolbar\d) must never appear in generated step arguments. qcs gen validate enforces this.
  • Normal replay does not call an LLM. Healing opens only after a deterministic failure; it produces a reviewable patch.

Recorder Details

Screenshot-Only AI Surface

During recording, AI receives screenshots and returns actions. Java DOM is not sent to AI. The Python recorder maps returned coordinates to local Java-agent DOM and records only the actioned element in the repository.

Readiness Before AI

The recorder and replay wait for Oracle Forms readiness using qcs_java_agent.readiness. Avoid fixed sleeps. AI screenshots should be taken only after the form is stable and not busy.

Dedicated Session Diagnostics

Each run writes recordings/<run_id>/diagnostics/, including screenshots, Java DOM snapshots, readiness data, AI requests/responses, action calls, and coordinate mapping files.

Fail Fast Recording

Recording should stop clearly when expected values are not found, LOV lookup fails, the wrong form opens, or a required field/action cannot be verified. Do not record a misleading script.

Oracle Forms Runtime

Java Forms automation is owned by the local Java agent. It attaches to the running Oracle Forms JVM and performs extraction and replay with structured component descriptors.

Non-Negotiable Forms Launch Rule

After Oracle EBS login succeeds, call oracle_form_open immediately. It handles responsibility selection and function navigation internally. If RF.jsp downloads a JNLP or starts Forms, call java_form_launch immediately before any Java Forms interaction.

AI is an authoring and repair assistant, not the normal execution engine. Replay must first try deterministic repository resolution and Java/Playwright actions.

Forbidden AI

Team Development Rules

Put Changes In The Right Layer

  • Recorder behavior belongs in oracle_ai_agent.
  • Java Forms extraction/replay belongs in java-agent/ and qcs_java_agent.
  • Repository identity, naming, and patch logic belongs in qcs_repo.
  • User-visible generated script behavior belongs in generator and qcs_replay.script.
  • Runtime locators, assertions, and healing belong in qcs_replay.
  • Fleet, jobs, artifacts, and UI APIs belong in qcs_center and qcs_agent.

Keep The System Safe

  • Do not add LLM calls to the normal replay path.
  • Do not send Java DOM to AI during normal recording; AI sees screenshots, local code maps coordinates.
  • Do not use screenshot clicking for normal Java Forms replay.
  • Do not navigate responsibilities or menus before oracle_form_open.
  • Do not serialize credentials or keys into prompts, recordings, logs, reports, generated tests, or DB rows.
  • Do not hand-edit generated tests for lasting fixes. Update the generator or repository source.
