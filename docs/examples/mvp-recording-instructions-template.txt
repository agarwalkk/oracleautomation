MVP Oracle EBS R12 Recording Instructions

Important rules for the recorder:
- Use EBS_USER and EBS_PASSWORD from environment variables. Do not type or record literal credentials.
- Use only the test/sandbox Oracle EBS environment.
- Immediately after login is successful, call oracle_form_open. It handles responsibility selection and function navigation internally. Do NOT navigate to a responsibility or menu item first.
- If oracle_form_open results in a JNLP download or Java Forms launch, call java_form_launch immediately before any Java Forms interaction.
- Treat record identifiers, dates, quantities, and amounts as test data placeholders.
- Record a verification at the end of the flow.
